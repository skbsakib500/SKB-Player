# SKB Player

> A privacy-first Android video player.
> Local files. No ads. No tracking. No cloud.

[![Build](https://github.com/skbsakib500/SKB-Player/actions/workflows/build.yml/badge.svg)](https://github.com/skbsakib500/SKB-Player/actions)

## Features

- 🎬 Media3 ExoPlayer playback
- 🎨 AMOLED theme + Material3
- 📚 Playlists, favorites, watch later
- 🔖 Bookmarks + notes
- 📜 Watch history
- 🔍 Search
- 🎚️ Equalizer, AB repeat
- 💬 Subtitle delay/position/profiles
- 📐 Pinch zoom, auto-rotate
- 🖼️ PiP + background playback
- 🎯 Register as system video player
- 📱 Splash animation

## Requirements

- Android 7.0+ (API 24)
- Compose UI
- Kotlin 1.9.24

## Install

Download the latest debug APK from
[Actions](https://github.com/skbsakib500/SKB-Player/actions)
or build yourself:

    ./gradlew :app:assembleDebug

## Build

    git clone https://github.com/skbsakib500/SKB-Player.git
    cd SKB-Player
    ./gradlew :app:assembleDebug

## Tech Stack

- Kotlin + Jetpack Compose
- AndroidX Media3 ExoPlayer 1.4.1
- Material3
- Foreground service + MediaSession
- Min SDK 24, Target 34
